# 🖨️ QuickPrint

QuickPrint is a simple **campus printing and Xerox management system**. Students can upload PDFs, select printing options, place orders, and receive a token number. Shopkeepers can manage orders, update status, view files, and manage prices.

### 🛠️ Technologies
- HTML, CSS, JavaScript
- Java
- JDBC
- MySQL

### ▶️ Run
1. Setup MySQL using `database/schema.sql`
2. Update `config.properties`
3. Run `run.bat`
4. Open `http://localhost:8080`

## 🔄 Workflows

### 👨‍🎓 Student Workflow
1. Open QuickPrint
2. Upload PDF
3. Select print type, sides, and copies
4. Enter required details
5. Place the order
6. Receive a token number and estimated time
7. Track order status
8. Collect the document when ready

### 🏪 Shopkeeper Workflow
1. Open Shopkeeper Dashboard
2. View incoming orders
3. Check order details and PDF
4. Start processing the order
5. Update status: **Pending → Printing → Ready**
6. Student collects the document
7. Mark order as **Collected**
